# Flipkart Automation - Selenium Java

This project automates the product search and data extraction process on Flipkart.

## 🚀 Features
* **Bypass Login Popups**: Automatically detects and closes intrusive login layers.
* **Dynamic Tab Switching**: Handles parent-to-child window transitions seamlessly.
* **Data Extraction**: Captures Product Title, Price, and Page Verification status.
* **Robust Locators**: Uses XPath with `translate()` for case-insensitivity and `ancestor` axes.
